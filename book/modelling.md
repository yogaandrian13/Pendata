# Modelling

Modelling adalah tahap membangun model prediktif atau deskriptif menggunakan algoritma machine learning atau data mining.

## 4.1 Pemilihan Algoritma

Klasifikasi: Decision Tree, Random Forest, SVM, Neural Networks, Logistic Regression Regresi: Linear Regression, Ridge, Lasso Clustering: K-Means, Hierarchical Clustering, DBSCAN Association: Apriori, FP-Growth Pemilihan algoritma didasarkan pada: Jenis masalah (klasifikasi, regresi, clustering) Karakteristik data Ukuran dataset Interpretabilitas yang diinginkan.

## 4.2 Training Model

Memasukkan data latih ke dalam algoritma Parameter tuning: Menyesuaikan hyperparameter untuk performa optimal Cross-validation: Mengevaluasi model dengan beberapa subset data Monitoring proses training: Memastikan tidak ada error atau warning.

## 4.3 Evaluasi Model

Metrik evaluasi untuk klasifikasi: Accuracy, Precision, Recall, F1-Score ROC-AUC Curve Confusion Matrix Metrik evaluasi untuk regresi: RMSE (Root Mean Square Error) MAE (Mean Absolute Error) R-squared Interpretasi hasil: Apakah model memenuhi kriteria keberhasilan yang ditetapkan di tahap Business Understanding?

## 4.4 Model Selection

Membandingkan performa beberapa algoritma Memilih model terbaik berdasarkan metrik evaluasi Mempertimbangkan trade-off antara akurasi dan kompleksitas model Memastikan model tidak overfitting atau underfitting.
